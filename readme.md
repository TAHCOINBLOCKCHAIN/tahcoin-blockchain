## What is Proof of View (PoV)?

Proof of View is a revolutionary consensus mechanism where **human attention** is the mining power. Instead of solving complex mathematical problems or requiring expensive hardware, miners validate the network by actively engaging with digital content.

### How It Works:

1. **Start Mining**: Click the "Start Mining" button on the Tahcoin dashboard
2. **Active Presence**: Stay visible on the page for at least **30 seconds**
3. **Earn Instantly**: Once verified, **₮0.00001 TAH** is automatically added to your wallet
4. **No Fees**: Zero transaction fees, instant liquidity
